# ChaarChaal

A browser-based Ludo game built with React, featuring an interactive board, turn-based gameplay, and responsive UI. Deployed to GitHub Pages... (inspired by mort3za/ludo)

> Reference inspiration: [mort3za/ludo](https://github.com/mort3za/ludo)

## Key Features

- React
- featuring an interactive board
- turn-based gameplay
- responsive UI
- Local persistence with automatic JSON state hydration
- One-click CSV export for filtered taskItems

## Getting Started

```bash
npm install
npm run dev
```

## Running Tests

```bash
npm test
```
